# Scripts

> Build, deployment, dan automation scripts.

## Available Scripts

| Script | Description |
|--------|-------------|
| `setup.sh` | Initial project setup |
| `dev.sh` | Start development environment |
| `deploy.sh` | Deploy to target environment |
| `db-seed.sh` | Seed database with test data |
| `generate-api-docs.sh` | Generate API documentation |
| `health-check.sh` | Check all services health |

## Usage

```bash
# Initial setup
chmod +x scripts/*.sh
./scripts/setup.sh

# Start development
./scripts/dev.sh

# Deploy to staging
./scripts/deploy.sh staging
```
