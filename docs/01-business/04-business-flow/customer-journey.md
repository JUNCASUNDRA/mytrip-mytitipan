## 1. Overview

Dokumentasi perjalanan pelanggan dari pertama mengenal produk hingga menjadi pengguna loyal.

## 2. Customer Journey Stages

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ AWARENESS│→│ CONSIDER │→│ PURCHASE │→│  USE     │→│ LOYALTY  │
│          │  │ -ATION   │  │          │  │          │  │          │
└──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
```

## 3. Journey Detail

| Stage | Touchpoint | Action | Emotion | Channel | Conversion Goal |
|-------|-----------|--------|---------|---------|----------------|
| **Awareness** | | Menemukan produk | | Social, Ads, WoM | Visit website/app |
| **Consideration** | | Eksplorasi fitur, baca review | | Website, App Store | Sign up |
| **Purchase** | | Memutuskan & membayar | | App, Payment | Complete payment |
| **Use** | | Menggunakan layanan | | App | Complete task |
| **Loyalty** | | Kembali, referral | | App, Social | Repeat purchase |

## 5. Moments of Truth

| Moment | Description | Impact | Our Strategy |
|--------|-----------|--------|-------------|
| Zero Moment (ZMOT) | Pertama kali search/discover | High | SEO, social proof |
| First Moment (FMOT) | First impression di app/web | Critical | UI/UX excellence |
| Second Moment (SMOT) | Experience menggunakan | Critical | Product quality |
| Ultimate Moment (UMOT) | Share experience | High | Referral program |
