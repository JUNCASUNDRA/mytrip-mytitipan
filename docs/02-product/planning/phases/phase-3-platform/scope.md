# Phase 3 Scope: Platform Discovery & Logistics

> **Status**: Draft **Last Updated**: 2026-06-14

## 1. Rationale
Phase 3 expands platform matching liquidity by shifting from a link-based sharing utility into an active internal marketplace with automated shipping integrations.

## 2. Core Capabilities
*   **Destination Discovery Feed:** Shoppers browse and search active travel itineraries by destination city or country.
*   **Creator Storefronts:** Curated storefront pages where travelers recommend custom item categories.
*   **Logistics courier integrations:** Automated domestic courier integrations (JNE/GoSend) for shipping label generation and real-time tracking webhooks.
*   **Dispute Override System:** Admin dashboard with automated escrow override refund mechanics.
