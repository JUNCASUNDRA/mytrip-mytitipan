# Shopper User Flow - Phase 1 (Foundation)

## Happy Path Flow

1.  **Open Trip Link**: Shopper lands on the shared trip page from an external link.
2.  **View Traveler Profile**: Shopper reviews the traveler's past history and reviews for trust.
3.  **Submit Product Request**: Shopper fills out the request form (Name, Quantity, Price Estimate, Photos, Notes).
4.  **Wait for Traveler Response**: Shopper tracks the request status on their dashboard.
5.  **Track Request Status**: Shopper sees updates as the traveler moves through lifecycle stages.
6.  **Confirm Receipt**: Shopper manually confirms they have received the item.
7.  **Submit Review**: Shopper leaves a star rating and text feedback for the traveler.

## Exception Paths

- **Edit/Cancel Request**: Shopper can edit or cancel their request as long as it is still in "Requested" status.
- **Trip Expired**: If a trip has passed its dates, the "Submit Request" CTA is disabled.
