# Usability Testing Logs

This directory contains plans, scripts, and logs for user testing sessions to validate layouts and workflows across launch phases.

---

## Phase 1 Usability Hypotheses

1.  **Frictionless Requesting:** Shoppers can land on a shared trip URL and submit a structured item request in less than 2 minutes.
2.  **Dashboard Tracking Clarity:** Travelers easily understand how to manually advance requests through the simplified status pipeline (`Requested` → `Accepted` → `Purchased` → `Delivered`).
3.  **Trust without Escrow:** The request timeline log provides sufficient visibility to give shoppers confidence that their traveler is active.
